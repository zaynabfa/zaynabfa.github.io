## Novel Methodology for Neurally-Guided GAN-Based Image Synthesis

This undergraduate thesis project (2024-2025) developed a groundbreaking approach to reconstructing faces from EEG signals using StyleGAN2 and representational similarity mapping. The work achieved a final grade of 98% and ranks among the top theses in the department.

### Project Overview

The project bridges the gap between neural activity and visual reconstruction by developing a neural-guided GAN pipeline that integrates brain-image similarity structures to enable high-fidelity face reconstructions from EEG data.

### Key Components

- **EEG Data Collection**: Set up and collected whole-brain EEG data from 20+ participants during face viewing tasks
- **Representational Similarity Mapping**: Developed novel methods to map neural activity patterns to visual similarity structures
- **StyleGAN2 Integration**: Adapted StyleGAN2 for neural-guided generation using latent space similarity mapping
- **Pipeline Development**: Created end-to-end computational pipeline for real-time face reconstruction

### Methodological Innovation

The project's key innovation lies in applying **latent space similarity mapping** to bridge EEG data with generative AI models. This approach:

- Maps neural activity patterns to StyleGAN2's latent space
- Uses representational similarity analysis to guide generation
- Enables high-fidelity reconstructions that preserve facial identity and features
- Demonstrates the potential for brain-computer interfaces in visual reconstruction

### Results and Impact

- **High Performance**: Achieved 98% final grade, ranking among top theses
- **Conference Presentation**: Findings accepted for presentation at Canadian Association for Neuroscience (CAN) 2025
- **Methodological Contribution**: Novel approach to neural-guided generation
- **Future Applications**: Potential for brain-computer interfaces and neural prosthetics

### Technical Details

The pipeline integrates:

- **Preprocessing**: EEG signal cleaning and feature extraction
- **Similarity Analysis**: Representational similarity structure computation
- **Latent Mapping**: Neural activity to StyleGAN2 latent space projection
- **Generation**: High-fidelity face reconstruction from neural patterns
- **Validation**: Quantitative and qualitative assessment of reconstruction quality

This work represents a significant step forward in understanding how the brain represents visual information and demonstrates the potential for AI-assisted neural decoding applications.
